# Create Brewery

Аддон для [Create](https://github.com/Creators-of-Create/Create): варка алкоголя в духе плагина BreweryX.
Правильно настроенная линия всегда даёт 5★, а ошибки стоят звёзд.

Нужны Minecraft 1.21.1, NeoForge 21.1.235 или новее и Create 6.0.10. JEI необязателен, но с ним рецепты видны прямо в игре.

## Машины

| Машина | Что делает | Что нужно |
|---|---|---|
| Пивоваренный котёл | Вода + сырьё → сусло | Огонь снизу. Точный нагрев даёт 5★, перегрев — 3★ |
| Перегонный куб | Сусло → дистиллят | Огонь снизу и вал в порт сзади, нагрузка 4 SU на оборот. Нужная скорость видна в GUI. Занимает 2 блока в высоту: колонна передаёт клик, трубы и воронки машине снизу |
| Бочка для выдержки | Дистиллят или молодой напиток → выдержанный | Дерево в слоте и игровые дни. Сон ускоряет выдержку |
| Носик для розлива | Наполняет бутылки из соседней машины | Клик с бутылкой в руке или бутылки через воронку |

Всё связывается трубами и воронками Create: вода идёт в котёл, сусло из котла в куб, сырьё, дерево и бутылки подаются воронками.

Наведите курсор на котёл, куб, бочку или носик и удерживайте клавишу Ponder (по умолчанию `W`), чтобы посмотреть анимированное руководство.

## Напитки

На партию: 2 единицы сырья и 1000 мВ воды.

| Сырьё | Из котла | Куб (RPM) | Бочка (дни, дерево) |
|---|---|---|---|
| Пшеница | Пиво | Виски (32) | Выдержанный виски (3, дуб) |
| Яблоко | Сидр | Кальвадос (64) | Выдержанный кальвадос (2, берёза) |
| Картофель | Картофельная брага | Водка (96) | — разливается сразу |
| Сахарный тростник | Тростниковая брага | Ром (48) | Выдержанный ром (5, тёмный дуб) |
| Сладкие ягоды | Молодое вино | — | Вино (4, дуб) |
| Пчелиные соты | Молодая медовуха | — | Медовуха (2, ель) |

Молодое вино и медовуху разливают из котла в бутылку и кладут эту бутылку в бочку. Пустая бутылка возвращается в слот бутылок.

## Качество

- Итог определяет самый слабый этап.
- Скорость куба: небольшое отклонение прощается, половина нужной даёт 2★, вдвое выше нужной портит партию.
- Неподходящее дерево снижает итог до 3★.
- Готовый напиток, оставленный в бочке, теряет звезду за каждый лишний срок выдержки.
- Напитки на 1–2★ вызывают тошноту, 1★ ещё и отравляет, а испорченный напиток бьёт сильнее всего.

## Опьянение

Каждый напиток добавляет опьянение по своей крепости, со временем оно спадает. Сначала качается камера, с 25 единиц заплетается речь в чате, с 90 игрок отключается на 10 секунд и теряет управление.

## Свои напитки

Рецепты лежат в `data/brewery/recipe` и меняются через datapack. Необязательный блок `drink` описывает путь напитка:

```json
"drink": {
  "id": "cider", "alcohol": 15,
  "distilled": "calvados", "distilledAlcohol": 40, "distillTicks": 300, "idealRpm": 64,
  "aged": "aged_calvados", "agingDays": 2, "wood": "birch"
}
```

Название добавляется в перевод как `drink.brewery.<id>`.

## Разработка

```bash
gradlew build
```

```bash
gradlew runGameTestServer
```

`build` собирает мод и запускает юнит-тесты, `runGameTestServer` проверяет машины в настоящем мире. Текстуры и модели генерирует `tools/gen_art.py` (нужен Python с Pillow).
