# Новые напитки

## Зачем

Пользователь хочет больше напитков. Рецепты теперь неизвестны, поэтому новые сделаны интереснее для экспериментов:
- смеси из разных предметов;
- первый рецепт на сильном нагреве (Blaze Burner);
- незанятые обороты куба и породы дерева.

## Что добавляется

Только данные: рецепты в `data/brewery/recipe`, перевод, цвета, картинки бутылок. Код машин не меняется.

- **общая картинка браги `mash`:** у пульке, полынной и светящейся браги.

## Не цели

- Особые эффекты напитков (свечение и тому подобное) — отдельная механика.
- Таблица рецептов в README — рецепты скрыты.

## Ограничения

- Лишняя пшеница по-прежнему даёт пиво: у 3 пшениц пиво набирает 85 очков, а стаут только 25.
- Пример в README «Свои напитки» берёт акацию, которую теперь использует текила. Пример меняется на `mangrove`.
- Ни один рецепт не раскрывается игроку: в README, Ponder и подсказках они не появляются.

## Подходы

Был выбран один путь: напитки — это чистые данные поверх готовой цепочки котёл → куб → бочка. Отдельная механика для каждого напитка отвергнута: машины уже обобщены через `DrinkProfile`.
