# Эффекты напитков и похмелье

## Зачем

У напитков нет своего характера, а за пьянство нет расплаты. По образцу BreweryX:
1. **Эффекты:** каждый напиток даёт свой эффект, сила которого зависит от звёзд.
2. **Похмелье:** после сильного опьянения наступает похмелье, тем тяжелее, чем хуже были напитки. Это ещё одна причина варить качественно.

Пользователь одобрил оба пункта.

## Эффекты напитков

**Формат.** В блоке `drink` рецепта появляется необязательное поле `effects`: карта «стадия → список эффектов».

```json
"effects": {
  "tequila": [{"effect": "minecraft:speed", "seconds": 60}],
  "aged_tequila": [{"effect": "minecraft:speed", "seconds": 120, "amplifier": 1}]
}
```

- `amplifier` по умолчанию 0.
- Без поля напиток эффектов не даёт, так что старые рецепты и datapack работают как раньше.
- Стадия из ключа должна быть одной из стадий этого же рецепта (`id`, `distilled` или `aged`), иначе рецепт не загружается.
- Неизвестный эффект тоже не даёт рецепту загрузиться.

**Сила по звёздам.** Длительность умножается на коэффициент:
- 5★ — ×1;
- 4★ — ×0.75;
- 3★ — ×0.5;
- 1–2★ — эффекта нет.

Испорченный и мутный напиток эффектов не дают. Эффекты плохого качества (тошнота, отравление) работают как раньше и складываются с эффектами напитка.

**Когда действуют.** Эффекты накладываются при питье бутылки (`DrinkItem.finishUsingItem`). Профиль напитка ищется по стадии бутылки среди `id`, `distilled` и `aged` всех рецептов.

**Секретность.** В подсказке бутылки эффекты не пишутся. Игрок узнаёт их, когда выпьет.

**Эффекты в рецептах мода:**

| Стадия | Эффект на 5★ |
|---|---|
| `kvass` | спешка (haste) 60 с |
| `young_mead`, `mead` | регенерация 5 с / 10 с |
| `vodka` | огнестойкость 90 с |
| `aged_rum` | подводное дыхание 120 с |
| `stout` | сопротивление 60 с |
| `tequila`, `aged_tequila` | скорость 60 с / скорость 120 с, усиление 1 |
| `absinthe` | ночное зрение 120 с и тошнота 15 с |
| `glow_spirit` | свечение 60 с |
| `firefly_liqueur` | ночное зрение 180 с и свечение 60 с |

## Похмелье

Чистая логика вынесена в `drunk/HangoverRules` без Minecraft, с юнит-тестами.

**Долг похмелья.** У игрока появляется сохраняемое значение `hangover` (attachment, сбрасывается при смерти). Каждый выпитый напиток добавляет к нему `крепость / 5 × вес качества`:

| Качество | Вес |
|---|---|
| 5★ | 0.1 |
| 4★ | 0.4 |
| 3★ | 0.7 |
| 1–2★, испорченный, мутный | 1.0 |

Результат округляется.

**Когда наступает.** Когда опьянение опускается до 0, проверяется долг:
- если он не меньше **8**, игрок получает усталость (mining fatigue, усиление 0) и голод на `долг × 15 с`, но не дольше 5 минут, и сообщение в строке действия «Голова раскалывается…» / «Your head is pounding…»;
- после проверки долг обнуляется в любом случае.

**Как снять.** Выпить бутылку воды: эффекты похмелья снимаются. Молоко снимает их само, как и любые эффекты.

**Пример.** Три бутылки водки 5★ (крепость 40) дают `3 × 8 × 0.1 = 2.4 → 2`, похмелья нет. Три бутылки водки 2★ дают `3 × 8 × 1.0 = 24`, это 6 минут, урезанные до 5.

## Не цели

- Рвота и шатающаяся походка.
- Эффекты в подсказке бутылки.

## Подходы

- **Выбрано:** эффекты как данные в рецепте, по стадиям. Каждая стадия цепочки может действовать по-своему, datapack их настраивает.
- **Отвергнуто — эффекты в Java по id напитка:** напитки из datapack остались бы без эффектов.
- **Выбрано:** долг похмелья, который копится при питье и гасится, когда игрок протрезвел. Так учитывается и количество, и качество.
- **Отвергнуто — похмелье по пиковому опьянению:** не учитывает качество, а смысл похмелья — наказывать за плохие напитки.
