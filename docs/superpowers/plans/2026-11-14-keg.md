# Keg and Mugs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A keg block that holds 8 portions of one drink and pours them into reusable wooden mugs, keeping stars and signature.

**Architecture:** Pure rules in `keg/KegRules` (capacity, what may go in); `KegBlockEntity` stores one `ItemStack` "template" (a single bottle carrying the components) + portion count + empties; mugs reuse `DrinkItem` through a container hook. Art and models from `gen_art.py`.

**Tech Stack:** NeoForge 1.21.1, Create 6.0.10 (goggles API, fluid valve item), Java 21, JUnit 5, GameTests, Python+Pillow.

**Spec:** `docs/superpowers/specs/2026-11-14-keg-design.md`

### Task 1: Keg block, rules, filling and automation

- Test: `src/test/java/com/kostya/createbrewery/keg/KegRulesTest.java`, `gametest/BreweryGameTests.java`

**Interfaces (Produces):**
- `KegRules`: `static final int CAPACITY = 8`, `static final int EMPTIES = 8`; `static boolean accepts(int portions, boolean sameDrink, int empties)` (portions < CAPACITY && (portions == 0 || sameDrink) && empties < EMPTIES — the hand path passes `empties = 0`); `static int windowLevel(int portions)` → `0` when 0, else `ceil(portions * 4 / 8)` (1..4).
- `KegBlockEntity`: `ItemStack getDrink()` (template, count 1, or EMPTY), `int getPortions()`, `int getEmpties()`; `boolean pourIn(ItemStack bottle, boolean keepEmpty)` (true when accepted); `ItemStack pourOut()` → one portion as a copy of the template (count 1) or EMPTY, clears template at 0; `IItemHandler getItemHandler(Direction side)`: down → extract empties only; other sides → insert drink bottles only (store empty glass bottle). NBT: `Drink` (ItemStack), `Portions`, `Empties`. Implements Create's `IHaveGoggleInformation` (drink name, stars line, `gui.brewery.keg.portions` "%s/%s", signature line; empty → `gui.brewery.keg.empty`).
- `KegBlock`: horizontal facing, `IntegerProperty LEVEL` 0–4 updated on change; `useItemOn` with a `ModItems.DRINK_BOTTLE` stack → `pourIn` (survival: shrink bottle, give glass bottle); with mug → handled in Task 2 (leave a hook: `KegBlockEntity.pourOut()` is public). Breaking drops portions as bottles + empties.
- Lang: block `Keg`/«Бочонок»; `gui.brewery.keg.portions` "%s/%s"; `gui.brewery.keg.empty` "Empty"/«Пусто».
