# Port to 1.20.1 Forge — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole mod builds, runs and passes all its tests on Minecraft 1.20.1 Forge with Create 6.0.8.

**Architecture:** Strangler port. Task 1 switches the build to ForgeGradle/1.20.1 and parks every not-yet-ported source file under `port/todo/` (outside the source sets) so the build is green from the first commit. Each later task ports one slice back into `src/main/java` / `src/test/java` / resources and brings that slice's unit and game tests back with it. When `port/todo/` is empty, the port is complete.

**Tech Stack:** Minecraft 1.20.1, Forge 47.x, ForgeGradle 6, Java 17 (Gradle toolchain download), Create 6.0.8 (`com.simibubi.create:create-1.20.1:6.0.8-291:slim`), Ponder/Flywheel/Registrate versions Create 6.0.8 declares, JEI 1.20.1 (optional), JUnit 5, Forge GameTest.

**Spec:** `docs/superpowers/specs/2026-11-14-port-forge-1.20.1-design.md` (and, for behaviour, the 1.21.1 code it ports from: branch `create-brewery`, commit a043fcc).
